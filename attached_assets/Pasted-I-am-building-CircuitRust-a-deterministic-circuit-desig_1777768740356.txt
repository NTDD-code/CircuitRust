​Implement a validation layer that checks the circuit netlist against a set of rules:

​E006 (Type Mismatch): Warning/Error if an Analog Output is connected to a High-Speed Digital Input without isolation.
​E007 (Voltage Mismatch): Error if a 5V output drives a 3.3V sensitive pin (e.g., ESP32/STM32 logic levels).
​W005 (Floating Pin): Warn if an IC input pin is not pulled high/low or connected.
​W009 (Missing Decoupling): Suggest a 0.1uF capacitor for every VCC pin of an Integrated Circuit.

​Extend the component library to include metadata:
​pins: Array of objects (Name, Type: Power/Digital/Analog/Passive, MaxVoltage).
​footprint: Default KiCad footprint (e.g., Resistor_SMD:R_0603_1608Metric).
​Ensure every component in the UI categories (Microcontrollers, ICs, Transistors, etc.) maps to a real-world footprint.
​3. The Exporter Module:
​Build a function to transform the internal circuit state into a KiCad .net (Netlist) file format.
​Add an option to export a basic Proteus-compatible connection list.
​The export should include: Component designators (R1, C1, U1), Values, and Footprints.
​4. AI Assistant Integration (Vibe Coding):
​Refine the "AI Circuit Assistant" to act as a Linter.

​5. UI/UX Refinement:
